# 📊 MarketMind AI Frontend

MarketMind AI is a Small Business Sales Intelligence Platform that helps businesses monitor sales, manage inventory, generate invoices, and visualize business insights through an interactive dashboard.

## Features

- 🔐 User Login
- 👥 Role-Based Access (Owner, Store Manager, Sales Executive, Admin)
- 📊 Interactive Dashboard
- 📦 Inventory Management
- 🧾 Invoice Management
- 📁 Sales Upload
- ⚙️ Settings Page
- 📈 Sales Trend Chart
- 🏆 Top Selling Products
- ⚠️ Low Stock Monitoring

## Tech Stack

## How to Run

1. Clone the repository.
2. Navigate to the frontend folder.

```bash
cd frontend
```

3. Install dependencies.

```bash
pip install -r requirements.txt
```

4. Run the application.

```bash
streamlit run app.py
```
