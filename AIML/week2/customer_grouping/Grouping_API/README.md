# Day 3 - Customer Grouping API

## Objective

Develop a Flask API that returns the customer group for a given Customer ID using the customer segmentation results generated by the K-Means clustering model.

---

## Implementation

### 1. Load Required Files

- Loaded the customer segmentation dataset (`customer_segments.csv`).
- Loaded the trained K-Means model (`kmeans_customer_model.pkl`) using Joblib.

### 2. Flask API

Created a Flask application with the following endpoints:

#### GET /

Returns the API status.

**Response**

```json
{
    "message": "Customer Grouping API is running.",
    "endpoint": "/customer-group"
}
```

#### POST /customer-group

Accepts a Customer ID in JSON format and returns the corresponding customer group.

**Request**

```json
{
    "Customer ID": "AA-10315"
}
```

**Response**

```json
{
    "Customer ID": "AA-10315",
    "Customer Group": "High-Value Customers"
}
```

---

## Customer Groups

| Cluster | Customer Group |
|----------|----------------|
| 0 | High-Value Customers |
| 1 | Regular Customers |
| 2 | Low-Value Customers |

---

## Validation

The API performs the following validations:

- Checks whether JSON data is received.
- Verifies that the `Customer ID` field is present.
- Searches for the Customer ID in the segmentation dataset.
- Returns an error if the Customer ID is not found.
